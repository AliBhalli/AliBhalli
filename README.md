## 🚀 About Me

<p>
  Launching production ready web app is only half the development; making sure it remains fast and reliable is the  real challenge. As poorly developed apps grow, their data gets tangled and data pipelines usually clog up, which causes laggy clicks, messy code, and ghost data—for example, sold-out items still showing in stock. If you have experienced these apps, you will truly understand how I will eliminate these server bottlenecks and handle complex state management using Redux, so the UI mirrors the database even during the production stage. On the backend, I will eliminate the chance of crashes during high traffic by using perfectly indexed database schemas and preventing server overload using rate-limited REST APIs.
</p>

<ul>
  <li>🎓 <strong>Education:</strong> BS Computer Science</li>
